# ⚡ 현장 작업일지 & 정산 관리 Pro (Web & Mobile PWA)

통신, 네트워크, CCTV 기사용 **일일 현장 작업일지 작성 및 월간 정산 자동화 웹 & 모바일 애플리케이션**입니다.

---

## 🌟 주요 기능

1. **📱 모바일 특화 간편 등록**
   - 이동 중 한 손으로 날짜, 가입번호, 고객명, 작업 내역 원터치 입력
   - CCTV / 전주RN / 구내RN의 **1인 / 2인(0.8배율)** 모드 원터치 전환
   - 동행 파트너(이현종, 안세민, 김윤후 등) 및 주요 비고(완료, 댁내설변, 즉시개통 등) 퀵 칩 지원

2. **📋 엑셀형 작업일지 (PC 테이블 & 모바일 카드)**
   - PC에서는 엑셀 스프레드시트 형태의 풀 그리드 테이블 제공
   - 모바일에서는 한눈에 들어오는 카드 뷰 제공
   - 고객명, 가입번호, 비고 실시간 검색 및 필터링
   - **엑셀 다운로드 (.xlsx)** 및 **엑셀 가져오기 (업로드)** 완벽 지원

3. **📅 월간 캘린더**
   - 달력 날짜별 작업 건수 및 당일 예상 수당 한눈에 확인
   - 날짜를 터치하면 해당 일자 상세 작업 내역 확인 및 즉시 추가 등록 가능

4. **💰 정산 리포트 & 자동 계산기**
   - 제공해주신 엑셀 정산 공식 100% 반영:
     - 인터넷: 5,000원
     - 추가단말: 3,000원
     - CCTV: 1인 11,000원 / 2인 8,800원 (0.8배율)
     - 전주RN: 1인 15,000원 / 2인 12,000원 (0.8배율)
     - 구내·옥상RN: 1인 12,000원 / 2인 9,600원 (0.8배율)
     - 해지 / 구내공사 / 장애: 각 3,000원
     - 주간당직: 20,000원 / 시간외 출동: 26,375원
   - 건수 및 가중치(0.8) 분리 집계, 월합 정산액 및 인쇄 지원

5. **⚙️ 환경설정 & 단가표 커스텀**
   - 회사 정책에 맞게 언제든지 단가 변경 가능
   - LocalStorage 자동 영구 저장 & JSON 백업/복원 지원

## 🚀 실행 및 사용 방법

### 방법 1. 즉시 실행 (가장 간단)
폴더 안의 **`index.html`** 파일을 더블 클릭하여 크롬, 엣지 등의 브라우저로 열면 즉시 모든 기능이 작동합니다.

### 방법 2. 스마트폰과 함께 사용하기 (로컬 네트워크)
1. **`start-app.bat`** 파일을 더블 클릭하여 실행합니다.
2. PC 브라우저가 자동으로 열리며, 화면에 **스마트폰 접속용 주소 (예: `http://192.168.0.x:8080`)**가 표시됩니다.
3. 동일한 Wi-Fi에 연결된 스마트폰 브라우저로 해당 주소에 접속합니다.
4. 스마트폰 브라우저 메뉴에서 **[홈 화면에 추가]**를 누르면 앱스토어에서 다운로드한 앱처럼 홈 화면에 아이콘이 생성되어 단독 실행됩니다.

### 방법 3. 웹에 무료 배포 (인터넷만 되면 언제 어디서나 접속)
- GitHub Pages, Vercel, Netlify 등에 이 폴더의 파일들을 업로드하면 고유한 도메인 URL이 생성되어 전 세계 어디서든 스마트폰 앱으로 사용하실 수 있습니다.
